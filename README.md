# Tic-Tac-Toe AI Agents

## Overview
This project implements AI agents that learn to play a 3x3 Tic-Tac-Toe game. The coursework covers three key reinforcement learning algorithms:  

- **Value Iteration**  
- **Policy Iteration**  
- **Q-Learning**  

The agents are tested against provided rule-based agents, and you can also play against any agent, including your own.

## Project Goals
- Implement reinforcement learning algorithms for game-playing agents  
- Evaluate agent performance against rule-based strategies  
- Understand the dynamics of learning and planning in a discrete environment  

## Framework
A general framework for the Tic-Tac-Toe game and agents is provided.  
- Run each code cell in order  
- Replace placeholders marked with `< >` to implement your logic  

## Tasks
- Implemented Value Iteration, Policy Iteration, and Q-Learning agents  
- Tested agents against rule-based opponents and recorded performance metrics  
- Played against the agents to verify their strategies and learning  

## Tools & Technologies
- **Language:** Python  
- **Libraries:** numpy, random, matplotlib (for optional visualizations)  
- **Environment:** Jupyter Notebook
